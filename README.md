#CryptoBot


- Projeto de Chatbot

Esse projeto foi feito na época de altas de Criptomoeda. Ele lhe serve como um alerta: Se o preço sobe de um valor pré-definido pelo usuário, uma mensagem será enviada instantaneamente ao utilizador. Essa variável também pode ser utilizada para valores menores identificados anteriormente.

- Apenas o escopo do Projeto

Este projeto está rodando apenas localmente, sem ser hospedado no momento. Ele pode ser iniciado em sua máquina e testado. É de livre acesso a todos e pode-se utilizar de bom proveito dele. 

- Variáveis

Ele pode ser alterado em seu código-fonte para a necessidade prevista. Pode-se transformá-lo, a quaisquer utilidades, como alterar sua função para moedas físicas, como Real, Euro, Dolar, Iene. Vai da criatividade do dev =)
